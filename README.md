# Mahwous Perfume Assistant

أداة محلية لمتابعة كتالوجات العطور وتنظيم بيانات المنتجات، مع أدوات داخلية
لتحليل الملاحظات التي يرسلها العملاء فعلياً.

## التشغيل السريع على Windows

افتح PowerShell وانسخ الأوامر التالية بالترتيب:

```powershell
cd "C:\Users\Hp\Downloads\مساعدي في شراء العطور"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

ثم افتح الرابط الذي يظهر في PowerShell، وعادة يكون:
`http://localhost:8501`.

لتشغيل الواجهة البديلة Flask:

```powershell
cd "C:\Users\Hp\Downloads\مساعدي في شراء العطور"
.\.venv\Scripts\python.exe app.py
```

ثم افتح `http://localhost:5000`.

## المفتاح السري

بعض وظائف الذكاء الاصطناعي تحتاج مفتاح OpenRouter. أنشئ محلياً ملفاً باسم
`.env` بجانب هذا الملف واكتب فيه سطراً واحداً فقط:

```text
AI_KEY=ضع_مفتاحك_الجديد_هنا
```

لا تضع المفتاح داخل أي ملف Python أو في Git. إذا تسرب مفتاح سابق، ألغِه من
لوحة المزود وأنشئ مفتاحاً جديداً قبل التشغيل.

للتشخيص الإداري المحلي فقط، يمكنك إضافة رمز مستقل وطويل في `.env`:

```text
ADMIN_TOKEN=رمز_إداري_طويل_وعشوائي
```

مسار `/api/ai-check` لا يعمل من دون هذا الرمز، ويُرسل في الترويسة
`X-Admin-Token` عند الحاجة. لا يعرض المسار أي جزء من مفتاح الذكاء الاصطناعي
ولا ينفذ طلباً خارجياً.

## الاختبارات

بعد التثبيت نفّذ:

```powershell
cd "C:\Users\Hp\Downloads\مساعدي في شراء العطور"
.\.venv\Scripts\python.exe -m pytest -q
```

لاختبار اتصال المفتاح يدوياً، وهو طلب خارجي وقد يستهلك من الرصيد:

```powershell
.\.venv\Scripts\python.exe test_api.py
```

### عزل بيانات الاختبارات

`conftest.py` يوجّه `DATA_DIR` و`ARCHIVE_FILE` إلى مجلد مؤقت لكل اختبار، فلا
تكتب أي جولة اختبار في `archive.json` الحقيقي. هذا ليس تحسيناً اختيارياً:
قبل العزل كان `test_generation_flow` يضيف نص الـmock للأرشيف الحيّ في كل
تشغيل، وبلغ أثره 151 مدخلة متطابقة من أصل 500.

عند إضافة اختبار يلمس التوليد أو الأرشفة، لا تعطّل هذا العزل.

## خريطة الملفات

- `streamlit_app.py`: الواجهة الرئيسية للتجربة المحلية.
- `app.py`: واجهة Flask وواجهات API البديلة.
- `scraper.py`: جمع بيانات صفحات المتاجر العامة عبر المتصفح.
- `full_scraper.py` و`mahally_reviews_scraper.py`: جمع محدود لصفحات عامة، مع
  فحص `robots.txt` وفاصل زمني لا يقل عن خمس ثوانٍ لكل نطاق.
- `scrape_compliance.py`: سياسة السحب المشتركة؛ تتوقف عند الرفض أو تحديد
  السرعة ولا تحاول تجاوز الحماية.
- `customer_feedback.py`: طلب وتجهيز نصوص آراء أصلية من عملاء اشتروا فعلياً
  ووافقوا على النشر.
- `empathy_engine.py`: ملفات تعاطف وذكريات شمية مفترضة لاختبارات البحث الداخلي،
  مع وسم إلزامي يمنع اعتبارها مراجعات عملاء.
- `personas_engine.py` و`humanizer.py`: وحدات محاكاة وتحليل داخلية، وليست
  مصدراً لمراجعات منشورة باسم عملاء حقيقيين.
- `review_text.py`: المسار الموحّد للنص النهائي وبوابة التفرّد — مصدر واحد
  يستخدمه `app.py` و`streamlit_app.py` معاً. القاعدة: **يُفحص ما يُخزَّن**؛
  أي فحص تفرّد يجب أن يقع على النص بعد الأنسنة والتنظيف والقصّ، لا على مخرج
  الـAI الخام (فحص الخام ثم القصّ كان يُوحّد مخرجات مختلفة في نص واحد).
- `anti_repeat.py`: التطبيع العربي (توحيد ة/ه وأ/ا وى/ي) وكشف التكرار بعتبات
  متدرّجة حسب الطول، مع تتبّع الكلمات والبدايات المحروقة.
- `conftest.py`: عزل `DATA_DIR`/`ARCHIVE_FILE` في مجلد مؤقت لكل اختبار.
- `sites_app/`: واجهة Next.js منفصلة (مستودع git مستقل) تستهلك المحرّك عبر
  `MAHWOUS_API_URL`؛ لا تولّد نصاً محلياً.
- `test_*.py`: اختبارات التحقق الآلي.

## قواعد التشغيل

- اسحب فقط الصفحات العامة التي يجيزها الموقع و`robots.txt` وشروطه.
- استخدم بيانات المنافسين لتحليل الاتجاهات بصورة مجمعة، لا لنسخ نصوص العملاء.
- لا تنشر نصاً مولداً أو محاكياً على أنه تجربة عميل. اطلب الرأي من صاحب
  الطلب الحقيقي واحفظ مرجع الطلب وموافقته قبل النشر.
